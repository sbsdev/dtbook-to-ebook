* PROPOSED ADR-0006: Mark up notes as endnotes following the Nordic guidelines
- Deciders :: CE
- Date :: [2026-10-28 Mi]

** Context and Problem Statement

SBS moves all notes to a "Fussnoten" section at the end of the book,
with a "Zurück" backlink after each note. With the new module the
notes arrive there, but as plain ~<aside>~ elements without any
semantics, and the section itself has none either. Reading systems
cannot recognise them as notes.

The old fork produced:

#+begin_src html
<body epub:type="backmatter footnotes">
  <h1>Fussnoten</h1>
  <ol epub:type="footnotes">
    <li class="notebody" epub:type="footnote">
      <p>…</p>
      <p><a href="…">Zurück</a></p>
    </li>
#+end_src

~footnotes~ is not a value of the EPUB Structural Semantics
Vocabulary, ~doc-footnote~ semantics on list items are discouraged,
the note references carry no ARIA role and the backlinks no
~doc-backlink~ role.

The [[https://format.mtm.se/nordic_epub/2025-1/][Nordic Guidelines 2025-1]] and the [[https://kb.daisy.org/publishing/docs/html/notes.html][DAISY Knowledge Base]] agree:
sequentially numbered footnotes are handled as end notes:

#+begin_src html
<p>… <a id="ref1" href="#fn1" role="doc-noteref" epub:type="noteref">1</a> …</p>
…
<section role="doc-endnotes" epub:type="endnotes">
  <h2>Fussnoten</h2>
  <ol>
    <li id="fn1">
      <p>…</p>
      <p><a href="#ref1" role="doc-backlink">Gehe zur Referenz 1.</a></p>
    </li>
  </ol>
</section>
#+end_src

Notes marked with symbols (~*~) are the exception: each goes into its
own ~<aside role="doc-footnote" epub:type="footnote">~ near its
reference. Nordic places end notes at the end of each content file;
SBS collects them in a single section at the end of the book.

** Considered Options

- A :: Reproduce the markup of the old fork.
- B :: Keep the upstream ~<aside>~ per note and add
  ~role="doc-footnote" epub:type="footnote"~.
- C :: Use the Nordic/DAISY end-note markup (~section~ with
  ~doc-endnotes~/~endnotes~, ~ol~/~li~, ~doc-backlink~), keeping the
  SBS placement in a single section at the end of the book.

** Decision Outcome

Proposed option: *C*, because it is the current best practice, the
old markup uses a non-standard ~epub:type~ value and is no reference
worth reproducing, and ~compare-epub.bb~ already accepts ~endnotes~.
B would mark notes that are moved to the end of the book as footnotes,
which they no longer are.

Open question: backlink text. Keep the SBS "Zurück", or follow Nordic
and include the note number (e.g. "Zurück zur Referenz 1")?
