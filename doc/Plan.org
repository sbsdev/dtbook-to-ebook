Detailed implementation guidance for the SBS DTBook-to-EPUB3 converter.

[[file:Architecture_Decision_Records.org][Architecture_Decision_Records.org]]; the requirements are in [[file:Requirements.org][Requirements.org]].

* XSpec test strategy

One ~.xspec~ file per preprocessing XSLT, each testing the transform in
isolation (DTBook in, DTBook out):

| XSpec file                              | What to cover                                                         |
|-----------------------------------------+-----------------------------------------------------------------------|
| ~addBoilerplate.xspec~                  | copyright text present; i18n selects correct language                 |
| ~addImageDescriptionBoilerplate.xspec~  | boilerplate injected exactly once per ~imggroup~ with ~prodnote~      |
| ~addImageIds.xspec~                     | every ~img~ gets a stable id                                          |
| ~addImageRefs.xspec~                    | ~imgref~ inserted; ~aria-describedby~ wired; ~longdesc~ absent        |
| ~addFootnoteAnchor.xspec~               | anchor appears before each noteref                                    |
| ~addFootnoteBacklinks.xspec~            | each footnote gets a link back to its noteref                         |
| ~moveFootnotesToRear.xspec~             | all footnotes end up in the last rearmatter level                     |
| ~filterBrlContractionhints.xspec~       | ~brl:*~ hints removed                                                 |
| ~filterLinenumSpans.xspec~              | linenum spans removed                                                 |

Additionally, test the XSLT overrides applied as post-processing:

| XSpec file                  | What to cover                                                                                                                                        |
|-----------------------------+------------------------------------------------------------------------------------------------------------------------------------------------------|
| ~dtbook-to-epub3.sbs.xspec~ | epigraph → blockquote; prodnote → span; list ~hd~ retained; fake frontmatter → div; poems without ~hd~ → div; caption before image; no ~longdesc~ |
| ~package-doc.sbs.xspec~     | ~accessMode~/~accessibilityFeature~ present; ~alternativeText~ conditional on images-with-alt; ~accessModeSufficient~ values correct                 |

** Wiring into Maven

Place ~.xspec~ files under ~src/test/xspec/~. The ~xspec-maven-plugin~
(already in the build tree at ~utils/xspec-maven-plugin~) picks them up
automatically and runs them on ~mvn test~.

* Regression test driver (~compare-epub.bb~)

A Babashka script modelled on ~dp2/scripts/compare-braille.bb~ that
compares EPUB output between two Pipeline instances (production vs. test).

** Config (~compare-epub-config.edn~)

#+begin_src clojure
{:prod-url   "https://pipeline.prod.example.com"
 :test-url   "https://pipeline.test.example.com"
 :token      "Token <your-jwt-token>"
 :output-dir "/tmp/epub-cmp"   ; optional
 :limit      100}              ; optional
#+end_src

** Comparison approach

EPUB files contain timestamps and auto-generated IDs, so comparison
must be structural, not byte-for-byte. For each document pair:

1. Unzip both EPUBs.
2. Normalise each ~*.xhtml~ file: strip whitespace differences and
   auto-generated ~xml:id~ attributes, then compare serialised XML.
3. Compare ~content.opf~: metadata elements and spine; ignore ~dc:date~
   and ~dcterms:modified~.
4. Compare ~nav.xhtml~ / ~toc.ncx~: navigation structure only.
5. Check presence (not content) of ~accessibility.css~.
6. On mismatch: save a ~diff --unified~ patch to the output directory.

** Comparison dimensions

| Dimension                | Pass condition                                                                                                       |
|--------------------------+----------------------------------------------------------------------------------------------------------------------|
| All XHTML files present  | same filenames in ~META-INF/container.xml~ spine                                                                     |
| XHTML structure          | same elements and text after normalisation                                                                           |
| OPF metadata             | same ~<meta>~ elements (excluding ~dcterms:modified~)                                                                |
| Footnotes in rearmatter  | ~footnotes~/~rearnotes~/~endnotes~ section exists when source has footnotes (the current converter uses ~footnotes~) |
| Caption order            | ~<figure>~ contains ~<figcaption>~ before ~<img>~                                                                    |
| ~aria-describedby~ wired | every ~<img>~ with a prodnote has the attribute                                                                      |
| No ~longdesc~            | attribute absent from all ~<img>~ tags                                                                               |
| Accessibility metadata   | ~schema:accessMode~ and ~schema:accessibilityFeature~ in OPF                                                         |
| Boilerplate              | first ~<section>~ contains expected copyright text                                                                   |

Document selection: find the most recent N documents on the production
server that have an EPUB product. 100 documents gives good coverage.
