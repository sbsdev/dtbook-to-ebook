#+title: Deviations from the Production EPUBs
#+language: en

Since [[file:adr/0006-nordic-guidelines.org][ADR-0006]] the goal is no longer to reproduce the EPUBs of the old
fork, but to follow EPUB 3 and the Nordic Guidelines 2025-1, using
upstream DAISY Pipeline functionality wherever possible. This file
collects where the new EPUBs differ from prod and why, as the basis
for the review with marketing. [[file:Requirements.org][Requirements.org]] remains the record of
what the prod EPUBs implement.

Reasons:
- Guidelines :: required by the Nordic Guidelines 2025-1
- EPUB :: required by EPUB 3.3/3.4 or flagged by EPUBCheck
- Upstream :: what the upstream converter produces, not changed by us

Status:
- done :: the new output is as described
- open :: the new output still differs from the guidelines, see Phase 3b in [[file:Plan.org][Plan.org]]
- regression :: differs from prod and from the guidelines only because of
  upstream; will be fixed back to prod, and the row removed once it is

Observed on document 13879 ("Das Herz eines Boxers").
