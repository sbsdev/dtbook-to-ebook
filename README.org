#+author: Christian Egli
#+language: en

SBS-specific EPUB3 converter for the [[https://daisy.org/activities/software/daisy-pipeline/][DAISY Pipeline 2]].

Converts DTBook XML to EPUB3 using the standard DAISY Pipeline
~dtbook-to-epub3~ script, with SBS-specific preprocessing, CSS, and
accessibility metadata layered on top as a thin wrapper module.

See [[file:doc/adr/0001-standalone-module.org][ADR-0001]] for the background and the
decision to replace the old Nordic migrator fork with this module.
See [[file:doc/Plan.org][doc/Plan.org]] for the XSpec test strategy, regression test design,
and phased development sequence.

* Requirements

- Java 8
- Maven 3.5+

* Build

#+begin_src sh
mvn clean package
#+end_src

* Test

#+begin_src sh
mvn test
#+end_src

Run a single XSpec test:

#+begin_src sh
mvn test -Dxspec.includes=**/addBoilerplate.xspec
#+end_src

* Release

Updates the version number in the pom, tags the release (=v<version>=)
and pushes. GitHub Actions then builds the =.deb= and attaches it to the
GitHub release. Nothing is deployed to Maven Central.

#+begin_src sh
export JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64
mvn release:clean release:prepare -DdryRun=true
mvn release:clean release:prepare
#+end_src

* Architecture

The module is a single OSGi bundle that wraps the standard DAISY
Pipeline ~dtbook-to-epub3~ script. The SBS delta consists of:

- *13 preprocessing XSLTs* applied to the DTBook before conversion
  (boilerplate injection, footnote relocation, image ref wiring, etc.)
- *~accessibility.css~* with SBS-specific visual adjustments
- *Post-processing* for OPF accessibility metadata and content
  structure corrections
- *~translations.xml~* for i18n boilerplate (Italian, Sursilvan)

#+begin_example
DTBook
  └─▶ SBS preprocessing (13 XSLTs)
        └─▶ daisy:dtbook-to-epub3  (standard, upstream)
              └─▶ SBS post-processing (metadata, CSS injection)
                    └─▶ EPUB3
#+end_example

* Regression testing

~scripts/compare-epub.bb~ compares EPUB output between two Pipeline
instances (e.g. production vs. test). Modelled on
[[file:~/src/dp2/scripts/compare-braille.bb][dp2/scripts/compare-braille.bb]].

#+begin_src sh
./scripts/compare-epub.bb compare-epub-config.edn
#+end_src

Config format (~compare-epub-config.edn~):

#+begin_src clojure
{:prod-url   "https://pipeline.prod.example.com"
 :test-url   "https://pipeline.test.example.com"
 :token      "Token <your-jwt-token>"
 :output-dir "/tmp/epub-cmp"   ; optional
 :limit      100}              ; optional
#+end_src
